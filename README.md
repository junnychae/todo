# 할 일 (Todo)

빌드 도구나 서버 없이 브라우저만으로 동작하는 할 일 관리 앱입니다.

## 실행

`index.html`을 더블클릭해서 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 기능

- 할 일 추가, 완료 표시, 수정, 삭제
- 전체 / 진행 중 / 완료 보기 (주소의 `#/active`, `#/completed`로 유지)
- 모두 완료 표시, 완료 항목 한 번에 삭제
- 진행률 표시
- 삭제 후 5초 동안 실행 취소 (토스트 버튼 또는 `Ctrl+Z`)
- 브라우저 `localStorage`에 자동 저장, 다른 탭과 동기화
- 라이트/다크 모드 자동 전환, 모바일 화면 대응
- 한글 입력(IME) 조합 중 Enter 처리 (마지막 글자 중복 방지)

## 단축키

| 키 | 동작 |
| --- | --- |
| `Enter` | 할 일 추가 / 수정 저장 |
| `Esc` | 입력 지우기 / 수정 취소 |
| 더블클릭 | 할 일 수정 |
| `Ctrl+Z` | 방금 삭제한 항목 되살리기 |

수정 중에 내용을 모두 지우고 저장하면 그 할 일은 삭제됩니다.

## 파일 구성

```
index.html   화면 구조
style.css    스타일 (라이트/다크 테마)
app.js       상태 관리, 저장, 렌더링, 이벤트 처리
```

## 데이터

할 일 목록은 브라우저의 `localStorage`에 `todo-app.v1` 키로 저장됩니다.
브라우저 데이터를 지우면 목록도 함께 지워지고, 다른 브라우저와는 공유되지 않습니다.
